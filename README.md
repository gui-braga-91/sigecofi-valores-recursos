# SIGECOFI - Módulo de Valores e Recursos

Protótipo interativo desenvolvido para o módulo de **Valores, Recursos e Fracionamento de Projetos** do sistema SIGECOFI.

## 🔗 Demonstração Online
[Clique aqui para testar o sistema](https://gui-braga-91.github.io/sigecofi-valores-recursos/)

## 🛠️ Tecnologias Utilizadas
* HTML5
* CSS3 (Design System responsivo)
* JavaScript (ES6+ Nativo e Reativo)

## 📌 Funcionalidades Principais
* **Cálculo Reativo em Tempo Real:** Atualização automática de porcentagem e valor fracionado.
* **Governança e Auditoria:** Modais de exclusão e inativação com registro de operador e data/hora.
* **Tabelas Interativas:** Redimensionamento manual de colunas (Drag & Drop) e agrupamento inteligente por projeto.
* **Experiência do Usuário (UX):** Alertas estilo Toast, máscaras de moeda/data em tempo real e cópia rápida de campos.
